# 爪迹 · 宠物成长与健康档案（可交互原型）

> 把每一次成长和照护，都留在同一份档案里。

爪迹不是宠物版朋友圈，也不是单纯的记录工具：它以**单只宠物的成长与健康档案**为核心，社区只是从记录、提醒和时间线自然延伸出的附加功能（约 70% 记录 / 30% 社区）。

---

## 一、启动与访问

```bash
cd zhuaji
npm install          # 首次运行
npm run dev          # 开发模式
```

- 访问地址：**http://127.0.0.1:5180**
- 生产构建：`npm run build`，预览：`npm run preview`（http://127.0.0.1:5181）

进入后可直接选择：

- **使用演示档案进入**：内置 2 只宠物（英短「团子」、柯基「麦麦」）与 20+ 条健康记录、同城内容。
- **作为新用户开始**：走完整建档流程（3 分钟内可完成建档 + 第一条记录）。
- 手机号登录为演示校验：任意 11 位手机号 + 验证码 `1234`。

数据保存在浏览器 `localStorage`，刷新后仍在。设置页可「重置为演示数据」或「注销并删除全部数据」。

## 二、技术栈与结构

- React 18 + TypeScript + Vite
- React Router（HashRouter，便于静态部署）
- lucide-react（统一图标体系）
- 原生 SVG 体重趋势图（无图表库依赖，按容器宽度实时重绘）
- 本地占位图资源全部为项目内 SVG，不依赖外网，不会出现破图

```
zhuaji/
├── public/img/            # 头像、照片、品牌图（本地 SVG 占位）
├── scripts/               # 资源生成、浏览器自检脚本（不参与构建）
└── src/
    ├── lib/api.ts         # ★ 集中式数据访问层（唯一数据出入口）
    ├── lib/format.ts      # 日期 / 年龄 / 体重 / 相对时间格式化
    ├── lib/health.ts      # 体重序列、提醒、疫苗进度等派生数据
    ├── data/seed.ts       # 演示数据（相对今天生成，永远"新鲜"）
    ├── store.tsx          # 全局状态（useSyncExternalStore + Toast + 弹层）
    ├── components/        # AppShell / 快捷记录 / 分享卡 / 体重图 / 通用 UI
    └── pages/             # 首页、档案、时间线、健康、同城、消息、设置、登录、建档
```

**接口替换说明**：所有读写都经由 `src/lib/api.ts` 的 `api.*` 异步方法（内部当前是 `localStorage` 模拟）。
替换真实后端时，只需把该文件里的方法改成 `fetch`，页面与状态层无需改动。
数据模型集中在 `src/types.ts`（User / Pet / PetMember / CareEvent / Reminder / Attachment / Post / Comment / LocalGroup / Activity / Follow-Block-Report）。

## 三、已实现功能

### 1. 建档与账号
- 登录 / 注册页（手机号 + 验证码演示校验）、演示档案入口、新用户入口
- 创建宠物档案：类型、名字、生日或到家日、头像为必填；品种、绝育、过敏、常去医院、紧急联系可后补
- 建档完成后立即引导「记录今天的样子 / 当前体重」
- 多宠物切换（首页右上、侧边栏、档案页三处均可切换）+ 添加另一只宠物
- 档案编辑、宠物资料查看

### 2. 快捷记录（底部 + / 侧边栏「记录」/ 首页快捷入口）
- 体重：数值、日期、照片、备注 → 保存后立即显示**相对上次的变化**
- 疫苗：类型（可快选）、接种日期、医院、凭证照片、备注
- 驱虫：体内 / 体外 / 体内外、药品、日期、备注
- 就诊与用药：医院、原因、医生记录摘要、用药、费用、附件
- 照片 / 日常：照片（支持本地选图，自动压缩）、标题、备注
- 疫苗 / 驱虫 / 就诊支持「沿用上次信息」
- 疫苗与驱虫保存后**询问是否设置下次提醒**（含一年后 / 半年后 / 三个月后快捷选项）
- 必填项校验、错误提示、保存中状态、成功反馈；体重保存后自动完成「本周体重记录」提醒

### 3. 首页（记录优先）
- 宠物档案头（头像、名字、品种、年龄、当前体重、绝育状态）
- 「今天需要关注」：7 天内到期与逾期提醒，可就地记录 / 标记完成，含逾期标识
- 快捷记录 5 个入口
- 最近健康摘要（体重 + 近 30 天变化 + 趋势图 + 疫苗 / 驱虫 / 本月记录）
- 最近一条时间线记录
- 本月回顾卡、同城精选（仅 2 条）、隐私默认设置说明
- 无宠物 / 无记录 / 无提醒的空状态引导

### 4. 时间线
- 按时间倒序、按月份分组的纵向时间线，6 类事件使用不同图标与节点色
- 类型筛选（全部 / 体重 / 疫苗 / 驱虫 / 就诊 / 照片 / 日常，带数量）
- 每条记录可生成分享卡、可删除（二次确认）
- 「已分享」标记、照片回顾、档案创建起点节点
- 成长卡：本月成长卡 / 年度成长报告 / 生日卡，自动统计并支持复制文案、发布到同城

### 5. 健康
- 体重趋势图（SVG，含最新值、30/90 天变化、趋势提示语，仅提示不诊断）
- 疫苗完成进度、接种记录、下次提醒（可设置 / 推迟）
- 驱虫日历（当月标记已记录与下次提醒）+ 驱虫记录
- 就诊与用药记录（医院、医生记录、用药、费用、附件）
- 健康附件汇总
- **一键导出近半年看诊摘要**（可复制 / 下载 .txt，含免责说明）
- 提醒清单（完成 / 推迟）

### 6. 同城（社区附加功能）
- 首次进入的位置说明（仅城市 + 行政区，不采集精确坐标）
- 动态 / 经验问答 / 品种小组 / 线下活动四个分区
- 动态与问答支持行政区筛选、点赞、评论、举报、拉黑
- 医疗经验内容强制显示「个人经验，不替代兽医建议」
- 品种小组加入 / 退出、活动报名 / 取消报名
- 分享入口：从时间线选记录 → 带图分享

### 7. 分享与可见范围
- 分享卡预览（宠物头像、名字、事件摘要、照片、品牌脚注）
- 可见范围三档：**仅自己可见（默认）** / 同城可见 / 关注者可见
- 「隐藏具体位置」开关、附带照片开关
- 私密保存不会发布到同城；公开发布后同城顶部立即出现
- 发布成功 Toast 带「去看看」快捷跳转

### 8. 消息、设置与隐私
- 消息页：健康提醒（推迟 / 完成）、同城互动（评论提醒）
- 设置：昵称、城市与行政区、关注者私信开关（默认关闭）
- 数据：导出全部数据 JSON、导出看诊摘要、重置演示数据、注销账号并删除全部数据
- 已拉黑用户管理
- 举报（5 类原因）、拉黑（含说明）、解除拉黑

### 9. 状态完整性
- 加载：启动骨架屏、页面级骨架、列表骨架、保存中按钮态
- 空状态：无宠物、无记录、无提醒、无同城内容、筛选无结果、无互动、无附件
- 错误：启动读取失败、导出无数据、同城刷新离线、表单校验、404 页面
- 成功：Toast 反馈 + 页面数据实时更新（时间线 / 趋势图 / 提醒状态联动）

## 四、设计与实现要点

- **配色**：深青绿 `#0e6b5c` 为主，珊瑚橙 `#d96340` 用于行动与健康提醒，中性白 / 浅灰 / 暖米色分区；无紫色渐变、无装饰球
- **圆角**：卡片与弹层统一 ≤ 8px；头像与标签为圆形 / 胶囊
- **图标**：全部使用 Lucide，工具型操作以「图标」或「图标 + 短文本」呈现
- **稳定尺寸**：按钮、标签、统计数字使用固定高度与 `tabular-nums`，避免数字变化引起跳动
- **响应式**：≥960px 左侧导航 + 右侧内容；≥1180px 双栏（主内容 + 辅助栏）；移动端底部 5 项导航 + 右下角记录 FAB
- **可访问性**：语义化标签、`aria-*`、键盘 Esc 关闭弹层、focus-visible 焦点环、`prefers-reduced-motion`
- **自检脚本**：`node scripts/shots.cjs`（桌面 1440 / 移动 390 全页面截图 + 横向溢出检测）、`node scripts/flow.cjs`（建档 → 记录 → 提醒 → 分享 → 评论全链路）

已实测：桌面 1440×940 与移动 390×844 下所有页面**无横向溢出、无文本重叠、无空白破图**；核心链路无控制台报错。

## 五、未实现 / 受限（明确说明）

以下内容**未实现**，页面上也不做「假可用」的装饰：

1. **真实后端与鉴权**：登录为演示校验，数据存在浏览器本地；无服务端账号体系、无多设备同步。
2. **家庭共享成员**：仅展示当前主要照护人与成员结构，「邀请成员」按钮会明确提示「下一版本开放」，不可真正邀请。
3. **照片上传服务**：选图后仅压缩保存在本地浏览器（`localStorage`），未上传对象存储，换设备不可见。
4. **站内私信**：仅有「关注者私信」开关，未实现会话与消息收发。
5. **关注关系**：可见范围中的「关注者可见」已作为选项与文案存在，但没有完整的关注 / 粉丝列表与推送。
6. **举报后台**：提交后本地隐藏该内容并给出 24 小时处理承诺，无真实审核后台。
7. **活动报名与小组**：报名 / 加入为本地状态，无主办方确认、无通知推送。
8. **成长卡导出为图片**：目前为页面内卡片 + 文案复制 / 发布到同城，未做 Canvas 导图与下载。
9. **提醒推送**：只有站内待办，没有浏览器推送 / 短信 / App 通知。
10. **其他物种**：第一版仅猫与狗。
11. **精确地图、实时距离、在线问诊、AI 诊断、电商、推荐算法**：按需求明确不做。

## 六、三个自检问题的当前答案

1. **新用户能否 3 分钟内完成建档和第一条记录？**
   能。建档必填 4 项（类型 / 名字 / 日期 / 头像），完成后直接给「记录今天的样子 / 当前体重」两个入口，体重只需 1 个数字。
2. **四周后是否仍愿意记录？**
   依赖三点设计：记录默认私密不制造表演压力；提醒只在疫苗 / 驱虫 / 体重这类真实节点出现，无连续签到与断签惩罚；每次记录都会进入趋势、时间线和看诊摘要，产生「以后用得上」的价值。
3. **从时间线分享到同城后，能否获得有价值的回应？**
   分享自动带宠物信息与事件摘要、默认私密、需主动选范围；同城按行政区聚合、医疗内容强制免责，问答区更偏「具体经验」而非泛泛点赞。
